# Intera

**Digital experiences built for what's next.**

Intera is a digital agency and product design studio focused on creating thoughtful digital experiences through **design, technology, and strategy**.

We help businesses turn ideas into modern, scalable, and user-friendly digital products.

## What We Do

- **UI / UX Design** — Research, user flows, wireframes, prototypes, and polished interfaces.
- **Web Development** — Modern, responsive, and scalable websites and web applications.
- **Mobile App Development** — User-focused mobile applications built for iOS and Android.
- **IT Consultant** — Technology consulting, technical planning, architecture, and digital transformation.
- **Graphic Design** — Branding, visual identity, marketing materials, and digital assets.

## Design Direction

Intera's visual direction is built around a **clean, modern, premium, and approachable** aesthetic.

The interface focuses on:

- Clear typography
- Strong visual hierarchy
- Generous whitespace
- Subtle blue accents
- Responsive layouts
- Purposeful animations
- Accessible UI components
- Consistent design patterns

The design is inspired by modern digital agency and product studio websites while maintaining its own visual identity.

## Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

Build for production:

```bash
npm run build
```

Run the production build:

```bash
npm run start
```
